Built for people with more than one Claude

A personal account, one or two for work, a spare for when a usage limit runs out. Chromium makes you choose between logging out and in all day, or running a browser profile per account. Claude Profiles keeps each account's claude.ai session and swaps between them in your normal browser, so everything else you are signed in to stays put.

One-click switching

Pick an account in the popup. Your claude.ai tabs reload into it.

Session checks

See at a glance who is signed in, expiring soon or signed out. The toolbar badge counts the signed-out ones.

Agent friendly

ccp switch, ccp open-for <url> and a local API let scripts and coding agents use the right account too.

How it works

Each saved account is a cookie jar. Switching swaps the claude.ai cookies, checks the new session, and reloads your claude.ai tabs.

  1. Save
    Sign in once, name the account, press Save current.
  2. Switch
    The extension swaps the claude.ai cookies and checks the new session. A revoked session rolls back, so you are never left half signed in.
  3. Reload
    Every claude.ai tab reloads into the account you picked.

Auto-swap for links

Someone shares a claude.ai link, or a Claude Code web session opens "couldn't be found" because you are on the wrong account. Claude Profiles tries your active account first, then each other saved account, and keeps the first one that can see the page.

If no saved account can see the link, it closes its tab, switches back, and tells you. The page check is a heuristic over the page's text.

Install in 60 seconds

You need macOS or Linux, Chromium, Chrome or Brave, Node 24 or newer and git. Open Claude Code and paste this prompt. It installs everything, asks you to load the extension (the one step no script can do), then helps you save each of your accounts. No sudo.

Install Claude Profiles on this computer and set up all of my Claude accounts. Read https://github.com/kranners/chromium-claude-profiles/blob/main/INSTALL_PROMPT.md and follow the "Steps for the agent" section exactly.

Prefer to do it yourself? Manual install steps are in the README.

  1. Load the extension: in your browser open chrome://extensions, turn on Developer mode, choose Load unpacked, pick the extension/ folder.
  2. Sign in to claude.ai, open Claude Profiles, type a label and press Save current.
  3. Run ccp sign-in-another (or press "Sign in another account"), sign in to the next one, and save it with ccp save. Repeat. See the onboarding guide.

Privacy and safety

Local only

Saved sessions live in the extension's storage in your Chromium profile. The only network calls go to claude.ai, to check each session.

User-only socket

The ccp command reaches the browser over a Unix socket only your own user can open. No debugging port, no open network port.

Cookies stay quiet

Cookie values are never logged, printed or sent anywhere. Read the code: it is short, open source and has tests.

Treat saved sessions like passwords. Read SECURITY.md for the full picture.

FAQ

Can I use two accounts at the same time?

No. Chromium keeps cookies per profile, not per tab, so one claude.ai account is active in the browser at a time. A switch reloads your claude.ai tabs, so finish your message first.

Does it change my Claude in Chrome login?

No. It swaps the claude.ai website session only. The Claude in Chrome extension keeps its own login.

Should I log out of an account in claude.ai?

Never log out of a saved account: logging out revokes the session and the saved copy stops working. Use "Sign in another account" in the popup instead.

An account says "Signed out". What now?

Switch to the browser's current account, use "Sign in another account", sign in to the one that expired and save it under the same label. The troubleshooting guide has more.

Does it work on Windows or Linux, or in Chrome?

macOS and Linux with Chromium, Google Chrome or Brave. Windows is not supported.
